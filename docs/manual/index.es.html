Control de espectáculos · reproducción de cues

Manual de usuario de OpenQ

OpenQ lleva un espectáculo a partir de una lista de cues. Cada pulsación de GO dispara la siguiente: sonido, vídeo, texto en una pantalla, fundidos, esperas o mensajes a otros equipos. Este manual explica cómo montar una lista de cues, llevarla en directo y controlarla desde otros dispositivos.

Idioma

OpenQ habla español, gallego e inglés. La primera vez que se abre pregunta el idioma, y se cambia cuando quieras en Ajustes → General → Idioma. Este manual usa los nombres en español de menús, pestañas y botones, por ejemplo Ayuda → Manual de usuario; algunas palabras del oficio, como cue, GO o Fade, se quedan en inglés. Las capturas muestran la interfaz en inglés.
