OpnQ User Manual

OpnQ runs a show from a list of cues. Each press of GO fires the next one: sound, video, text on a screen, fades, waits, or messages to other gear. This manual covers building a cue list, running it live, and controlling it from other devices.

Language

OpnQ speaks English, Spanish and Galician. It asks for a language the first time it starts; change it any time in Settings → General → Language.
