Show control · cue playback

OpenQ User Manual

OpenQ runs a show from a list of cues. Each press of GO fires the next one: sound, video, text on a screen, fades, waits, or messages to other gear. This manual covers building a cue list, running it live, and controlling it from other devices.

01Getting started

OpenQ runs on Linux, macOS and Windows. Video needs the system FFmpeg libraries. To build and run it from the source folder:

cargo run --release                  # start with an empty show
cargo run --release -- show.openq    # open a saved show

Your first show

  1. Drag audio or video files from your file manager onto the window. Each file becomes a cue. You can also use File → Import media files….
  2. Add other cues from the toolbar above the cue list, or press Ctrl+1…0.
  3. Select a cue and set its options in the inspector at the bottom of the window.
  4. Click the first cue to put the playhead on it, then press Space (GO).
  5. Save with Ctrl+S. Shows are saved as .openq files. Media paths are stored relative to the show file, so you can move the show folder as a whole.
Tip

Keep the show file in the same folder as its media. Then the folder can be copied to another computer and opened there unchanged.

02The main window

  • Title bar: the show's name (a dot means unsaved changes) and the Edit / Show switch at the right.
  • Menus: File, Edit, Cue, Show, Video (stages and outputs), Remote, and View (geometry preview, engine log).
  • GO fires the cue at the playhead. The standby card shows that cue, with its notes underneath so the operator can read them before pressing GO.
  • Transport: pause pause all, play_arrow resume all, stop stop all. Next to them, the output meters show each device channel in dB.
  • Cue list: number, name, target (file details or the target cue), pre-wait, action time, post-wait and the continue arrow. Running cues turn green, and their action column counts down. A red error icon marks a missing file or target.
  • Active cues: every running cue with elapsed and remaining time, plus its own pause and stop buttons.
  • Inspector: the settings of the selected cue, in tabs.
  • Status bar: audio device, video status, OSC, remote connections and messages. A warning from the engine appears at the right and opens the engine log.

Working with the cue list

  • Click a cue to select it and move the playhead to it. Use Ctrl-click to select several cues, Shift-click for a range, and ↑ ↓ to move the playhead.
  • Drag cues to reorder them. Drop onto the middle of a group row to put cues inside it.
  • Double-click a number, name, pre-wait or post-wait to edit it in place. Enter commits and Esc cancels.
  • Click the continue column to cycle do not continue → auto-continue → auto-follow.
  • Right-click a row for start, stop, duplicate, delete and more.

03Edit and show mode

Edit mode is for building the show: everything can be changed. Show mode is for running it. The list is locked, the toolbar and inspector are hidden, and rows get bigger so they are easy to read in a dark booth. GO, stop, pause, hotkeys and moving the playhead all work in both modes.

Switch with the switch in the title bar, Show → Enter show mode, or Ctrl+E.

Stopping

Esc or the red stop button fades everything out over the stop-all fade time (see Settings). Press it again during that fade to stop instantly.

Double-GO protection ignores a second GO that comes within a short time of the first, so a bounced key doesn't skip a cue.

Every cue has a number (free text, like 4.2), a name, notes, a colour and an armed switch, all on the Basics tab. A disarmed cue is skipped by GO. Basics also sets an optional hotkey: a key that fires the cue directly, whatever the playhead is on.

05Timing and continues

Each cue has three times. The pre-wait runs between GO and the cue's action. The action is the cue itself: a sound playing, a fade running. The post-wait is counted from the start of the action and is used by auto-continue.

Continue modeWhat happens next
Do not continueNothing. The playhead moves to the next cue and waits for GO.

Chained cues start on exact sample boundaries, so a sequence keeps its timing however long it runs.

06Audio cues

Time & Loops

  • Trim: drag the start and end markers, or type the times. Drag the waveform to pan, and use Ctrl+scroll to zoom. A line shows the playback position while the cue runs.
  • Loops: set a play count, or loop until stopped.
  • Rate: varispeed. The pitch changes with the speed, like a tape machine.
  • Slices: double-click the waveform to add a slice marker. Drag it to move it, and right-click to delete it. Each slice plays a set number of times, or loops until a Devamp cue (or the OSC message /cue/<n>/devamp) releases it. The current pass then finishes and playback carries on. Use this for music that has to vamp until an actor's line.

Levels & Routing

Level and pan, plus a routing matrix from the file's channels to the outputs of the audio device. Each crosspoint has its own level in dB, so a stereo file can feed eight speakers.

EQ

Band types are high-pass, low shelf, peak, high shelf and low-pass. EQ enabled turns the whole EQ on and off.

Live changes

Level, pan, EQ and routing changes are heard straight away on a playing cue, so you can tune them during a run.

07Video and text cues

A video cue plays a movie (anything FFmpeg can play) or a still image. Stills show for a set time, or until stopped. Time & Loops has start and end trims, loops and hold last frame. The Audio tab sets the soundtrack's level and routing; the soundtrack plays through the mixer like an audio cue.

Geometry

  • Stage: which output the picture goes to. Without one, the first stage is used.
  • Fit: Fit shows the whole picture (letterboxed), Fill covers the stage and trims the overflow, Stretch fills it exactly, and Native size uses the file's own pixels.
  • Layer (higher draws on top) and opacity.
  • Position, scale and rotation. Position is a percentage of the stage: X 25% moves the picture a quarter of the stage to the right. Lock proportional to scale both axes together.
  • Crop: trims a percentage from the left, top, right and bottom. The rest of the picture stays where it was.

Geometry preview (View → Geometry preview, or Preview on the Geometry tab) draws the selected cue's stage with the picture in place, without opening a projector output. In edit mode, drag in the preview to move the picture, scroll to scale it, and double-click to centre it. For a Fade cue that changes geometry, the preview shows where the fade ends, with the starting position as a dashed outline.

Text cues

Text cues show typed text on a stage. The Text tab sets the text, size, colour, bold, alignment and how long it shows. The Geometry tab works as it does for video. Changes to the text appear at once on a cue that is showing.

08Fades

A Fade cue changes another cue while it runs. Choose the target cue, the duration and the curve (linear, S-curve or logarithmic), then tick what to change:

  • Level in dB, for audio and for video soundtracks.
  • Opacity, for video and text.
  • Geometry: position, scale, rotation and crop. This starts from the target's own geometry, so only the values you change will move.

Tick Stop target for a fade-out: the target stops when the fade ends. Pausing a fade freezes it, and resuming it continues with the time that was left.

09Stages and projection

A stage is one video output, such as a projector or a screen. Add stages in Settings → Stages. Each has a name and a canvas size in pixels.

Sending a stage to a display

In Video → Stage: name → Output, or with the Output dropdown in Settings → Stages, choose Window or one of the connected displays. A stage set to a display opens fullscreen on that display, and it opens there again when the show is loaded. If a display isn't listed, use Refresh displays. In a stage window, double-click or press F11 to toggle fullscreen.

Mapping

Edit mapping shows a test pattern on the stage with four corner pins. Drag the corners to fit the picture onto the screen (keystone correction), or hover a corner and nudge it one pixel at a time with the arrow keys. Reset mapping puts the corners back.

10Remote devices

A second computer running OpenQ on the same network can follow the show and run it. This could be the stage manager's laptop or a tablet at the tech table. The computer running the show is the main device, and it does all the playback. The other device shows its cue list, playhead, running cues and meters, and sends GO and other commands to it.

Pairing a device

  1. On the main device, open Remote → Share this OpenQ, tick Let paired devices connect, and click Pair a new device…. A code such as C9XR-E9HJ appears.
  2. On the other device, open Remote → Connect to another OpenQ, click Search and choose the main device. If the search finds nothing, type its address, which is shown in the main device's Remote window.
  3. Enter the code and click Connect. After the first time, connecting needs no code.

Roles

RoleThe device can
View onlyFollow the show: cue list, playhead, running cues and meters.
ControlAlso press GO, stop, pause and resume, move the playhead, and start or stop single cues.
Control & editAlso edit the show. Changes are saved on the main device.

Set the role new devices get, and change any device's role, in the main device's Remote window. Changes take effect at once. Remove disconnects a device straight away, and it has to pair again to reconnect. When a device disconnects, it gets its own show back. Media files stay on the main device, so add them there.

Security

Connections are encrypted and authenticated. A pairing code works for 5 minutes and 5 tries, and someone who records the network traffic still can't work it out from the recording. After pairing, each device logs in with its own secret key. An address that keeps failing is blocked for 5 minutes. The Activity list shows connections and rejected attempts.

Network

Remote access uses TCP port 53200, and the search uses UDP port 53201. A firewall on the main device has to allow both. On guest Wi-Fi the search may find nothing; typing the address still works.

11OSC and network cues

Turn on OSC remote control in Settings → General. It listens on UDP port 53000 by default. Cues are addressed by their number.

AddressAction
/goGO
/stop · /panicStop all with the fade · stop all instantly
/pause · /resumePause all · resume all
/playhead/next · /playhead/previousMove the playhead
/playhead/4.2Put the playhead on cue 4.2
/cue/4.2/startAlso stop, pause, resume, devamp

A Network cue sends one OSC message to other gear. Set the host, port, address (for example /eos/cue/12/fire) and arguments. Arguments are separated by spaces: numbers are sent as numbers, and text in quotes is sent as text.

12Settings

Edit → Settings… These are saved with the show.

TabSettings
GeneralStop-all fade time, double-GO protection, master volume, OSC on/off and port.
AudioOutput device. Changing it stops all playback. Routing matrices address this device's outputs.
StagesAdd and name stages, canvas size, output display, fullscreen, mapping.

Remote access settings and device keys belong to the computer, not the show. They live in ~/.config/openq/remote.json, readable only by your user account.

14Troubleshooting

ProblemTry
No soundCheck the status bar. If it says no audio, pick another device in Settings → Audio. Check the master volume and the cue's level and routing.
A cue shows a red error iconIts media file is missing or unreadable, or its target cue was deleted. If the file has moved, click Browse… on the cue's Time tab to find it again.
A video doesn't appearOpen the stage window from the Video menu. Check the cue's stage, opacity and layer, and look in View → Engine log for decoder errors.
GO seems to do nothingThe cue at the playhead may be disarmed, or the second press may have come within double-GO protection.
A remote device can't find the main deviceMake sure remote access is on and both are on the same network, then type the address shown on the main device.
"Pair this device again"The device was removed on the main device, or its key was forgotten. Open pairing on the main device and enter the new code.
