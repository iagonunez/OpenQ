Install OpnQ

In a terminal:

curl --proto '=https' --tlsv1.2 -fsSL https://github.com/iagonunez/OQup/releases/latest/download/install.sh | sh

Downloads the newest release (x86_64 or ARM64; a distribution from 2022 or later), installs missing sound and device libraries from your distribution's packages (it asks first) and adds OpnQ to your applications menu.

In a terminal:

curl --proto '=https' --tlsv1.2 -fsSL https://github.com/iagonunez/OQup/releases/latest/download/install.sh | sh

macOS 11 or later, Apple silicon or Intel. OpnQ ends up in Applications in your home folder.

In PowerShell:

powershell -ExecutionPolicy Bypass -c "irm https://github.com/iagonunez/OQup/releases/latest/download/install.ps1 | iex"

Windows 10/11, 64-bit. OpnQ is then in the Start menu.

The installer, OQup, downloads OpnQ with the LGPL FFmpeg libraries it uses and, with lighting, the OQVis 3D visualiser. Later: oqup update · oqup versions · oqup uninstall; oqup install --build-source compiles it on your computer instead, --no-lighting installs the cues only.

Step by step

OpnQ is installed by its installer, OQup. OQup downloads the newest release of OpnQ for your system, checks it, adds the FFmpeg libraries it uses for video (an LGPL build) and installs it with a menu entry. With the lighting workspace (the default) it also installs OQVis, the 3D visualiser that Open in OQVis starts. Your shows are never touched.

Before you start

You need an internet connection. On Linux OQup may need your password to install a few system libraries (sound, devices); it asks first.

Linux

  1. Open a terminal, paste the command below and press Enter: 
    curl --proto '=https' --tlsv1.2 -fsSL https://github.com/iagonunez/OQup/releases/latest/download/install.sh | sh
  2. The first step downloads OQup, checks it against the published checksum and puts it in ~/.local/bin. Then it starts.
  3. If system libraries OpnQ needs are missing (ALSA, PipeWire, udev), OQup lists them and asks before installing them with your distribution's package manager. Answer yes; the package manager asks for your password.
  4. Leave the terminal open until it says that OpnQ is installed.
  5. Open OpnQ from your applications menu (search for "OpnQ"), or type opnq in a terminal.

If the terminal says opnq: command not found, ~/.local/bin is not in your PATH yet. Add it once, then open a new terminal:

fish_add_path ~/.local/bin                                 # fish
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc   # bash (zsh: ~/.zshrc)

macOS

  1. Open Terminal (press ⌘ Space and type "Terminal").
  2. Paste the command below and press Enter: 
    curl --proto '=https' --tlsv1.2 -fsSL https://github.com/iagonunez/OQup/releases/latest/download/install.sh | sh
  3. The app is placed at ~/Applications/OpnQ.app, the Applications folder in your home folder, with FFmpeg inside it. Open it from the Finder (Go → Home → Applications) or with Spotlight.

Windows

  1. Open PowerShell: press the Start key, type PowerShell and press Enter.
  2. Paste the command below and press Enter: 
    powershell -ExecutionPolicy Bypass -c "irm https://github.com/iagonunez/OQup/releases/latest/download/install.ps1 | iex"
  3. When it is done, OpnQ is in the Start menu and listed under Settings → Apps → Installed apps.

Building on your own computer

oqup install --build-source compiles OpnQ (and OQVis) from the source code on your computer instead of downloading the release. OQup installs what the build needs first: a private copy of Rust if there is none, a C compiler and libclang, and FFmpeg (on Linux from your distribution's packages, after asking; on macOS Apple's Command Line Tools, then FFmpeg compiled from its source; on Windows Microsoft's C++ Build Tools, whose installer opens for you to accept). It needs several gigabytes of free space and the first build takes a long time; later ones are quicker.

If something goes wrong

  • oqup doctor shows what is installed and what an install still needs.
  • If the install stops, read the last lines it printed, fix the cause (usually a missing package or a cancelled installer) and run the command again.

Updating and removing

To get a newer version, run oqup update: it installs OpnQ again when a new version is released, the same way as last time. oqup versions lists the versions you can install, and oqup install --ref v0.4.0 installs one of them. To remove OpnQ, run oqup uninstall; it asks first. Add --purge to remove OQup's downloads, Rust, dependencies and build cache as well. On Windows you can also remove OpnQ from Settings → Apps → Installed apps. Your shows are never touched.

If you only need cues, oqup install --no-lighting installs OpnQ without the lighting workspace (no Lighting view, Light cues, fixture downloads or OQVis). Shows with a lighting design still open, keep it and play their Light cues. oqup install --lighting adds it back; --no-oqvis keeps the lighting but leaves OQVis out.

What it does

24 cue typesAudio, video, text, camera, live mic, groups, waits, fades, OSC, MIDI, timecode and more.
Sample-accurate timingPre- and post-waits, auto-continue and auto-follow, chained to the exact sample.
Mixer, EQ and effectsRouting matrix, 8-band EQ, reverb, delay, dynamics and more, edited live.
Object audioPlace sounds in a room of speakers and fly them around with fades.
Video and projectionMovies, stills, SVG and titles on any number of stages, with mapping and edge blending.
Animation and video effectsKeyframes, blend modes, colour effects and chroma key, drawn live by the GPU.
Timecode, MIDI and OSCFollow or send LTC and MTC, send MIDI and MIDI Show Control, take OSC from other gear and send it to lighting desks.
Remote devicesRun or edit the show from a laptop or tablet over an encrypted link.
Built for the boothShow mode, autosave and crash recovery, audio that reconnects by itself.
