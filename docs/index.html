Install OpenQ

In a terminal:

curl --proto '=https' --tlsv1.2 -fsSL https://github.com/iagonunez/oqman/releases/latest/download/install.sh | sh

Installs the build tools from your distribution's packages (it asks first), builds OpenQ and adds it to your applications menu.

curl --proto '=https' --tlsv1.2 -fsSL https://github.com/iagonunez/oqman/releases/latest/download/install.sh | sh

powershell -ExecutionPolicy Bypass -c "irm https://github.com/iagonunez/oqman/releases/latest/download/install.ps1 | iex"

Windows 10/11, 64-bit. Without Microsoft's C++ Build Tools, their installer opens first: accept it and let it finish. OpenQ is then in the Start menu.

Step by step

OpenQ is built on your own computer by its installer, oqman. The installer downloads the source code of the newest version, installs what the build needs (Rust, a C compiler, and FFmpeg for video), builds OpenQ and adds it to your applications. Your shows are never touched.

Before you start

You need an internet connection, several gigabytes of free disk space, and an administrator password on Linux and Windows (it is used to install system packages). The first install is the longest, because the whole program is compiled; on an older computer it can take a long time. Later updates are quicker, because the dependencies are already built.

Linux

  1. Open a terminal, paste the command below and press Enter: 
    curl --proto '=https' --tlsv1.2 -fsSL https://github.com/iagonunez/oqman/releases/latest/download/install.sh | sh
  2. The first step downloads the installer, checks it against the published checksum and puts it in ~/.local/bin. Then it starts.
  3. When it lists the system packages it needs (a C compiler, libclang, the ALSA and PipeWire audio headers, udev and FFmpeg), it asks before installing them with your distribution's package manager. Answer yes; the package manager asks for your password.
  4. If the computer has no Rust, oqman installs a private copy in its own folder. Any Rust already on the system is left alone.
  5. The build prints each crate it compiles. Leave the terminal open until it says that OpenQ is installed.
  6. Open OpenQ from your applications menu (search for "OpenQ"), or type openq in a terminal.

If the terminal says openq: command not found, ~/.local/bin is not in your PATH yet. Add it once, then open a new terminal:

fish_add_path ~/.local/bin                                 # fish
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc   # bash (zsh: ~/.zshrc)

macOS

  1. Open Terminal (press ⌘ Space and type "Terminal").
  2. Paste the command below and press Enter: 
    curl --proto '=https' --tlsv1.2 -fsSL https://github.com/iagonunez/oqman/releases/latest/download/install.sh | sh
  3. If the Mac has no Apple Command Line Tools yet, macOS opens Apple's installer. Accept Apple's licence, let it finish, then run the same command again.
  4. oqman builds FFmpeg from its source code, which takes a while. On an Intel Mac it also builds NASM, the assembler FFmpeg uses.
  5. The app is placed at ~/Applications/OpenQ.app, the Applications folder in your home folder. Open it from the Finder (Go → Home → Applications) or with Spotlight. Because you built it on this Mac, macOS does not show the "unidentified developer" warning.

Windows

  1. Open PowerShell: press the Start key, type PowerShell and press Enter.
  2. Paste the command below and press Enter: 
    powershell -ExecutionPolicy Bypass -c "irm https://github.com/iagonunez/oqman/releases/latest/download/install.ps1 | iex"
  3. If the computer has no Microsoft C++ Build Tools, their installer opens with the "Desktop development with C++" workload selected. Accept Microsoft's licence and let it finish; it is large and can take a while. oqman then carries on in the same window.
  4. oqman downloads FFmpeg (the shared LGPL build) and libclang from LLVM, then compiles OpenQ.
  5. When it is done, OpenQ is in the Start menu and listed under Settings → Apps → Installed apps.

If something goes wrong

  • oqman doctor shows what is installed and what the build still needs.
  • If the build stops, read the last lines it printed, fix the cause (usually a missing package or a cancelled installer) and run the command again. What already compiled is kept, so the second try is quicker.

Updating and removing

To get a newer version, run oqman update: it rebuilds OpenQ when a new version is released. To remove OpenQ, run oqman uninstall; it asks first. Add --purge to remove oqman's Rust, dependencies and build cache as well. On Windows you can also remove OpenQ from Settings → Apps → Installed apps. Your shows are never touched.

What it does

15 cue typesAudio, video, text, camera, live mic, groups, waits, fades, OSC and more.
Sample-accurate timingPre- and post-waits, auto-continue and auto-follow, chained to the exact sample.
Mixer, EQ and effectsRouting matrix, 8-band EQ, reverb, delay, dynamics and more, edited live.
Object audioPlace sounds in a room of speakers and fly them around with fades.
Video and projectionMovies, stills, SVG and titles on any number of stages, with mapping and edge blending.
Animation and video effectsKeyframes, blend modes, colour effects and chroma key, drawn live by the GPU.
Timecode and OSCFollow LTC or MTC, take OSC from other gear and send it to lighting desks.
Remote devicesRun or edit the show from a laptop or tablet over an encrypted link.
Built for the boothShow mode, autosave and crash recovery, audio that reconnects by itself.
