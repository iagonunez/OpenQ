Instala OpenQ

Nun terminal:

curl --proto '=https' --tlsv1.2 -fsSL https://github.com/iagonunez/oqman/releases/latest/download/install.sh | sh

Instala as ferramentas de compilación cos paquetes da túa distribución (pregunta antes), compila OpenQ e engádeo ao menú de aplicacións.

Nun terminal:

curl --proto '=https' --tlsv1.2 -fsSL https://github.com/iagonunez/oqman/releases/latest/download/install.sh | sh

macOS 11 ou posterior. Nun Mac sen as Command Line Tools de Apple, macOS pide instalalas primeiro; despois volve executar a orde. OpenQ queda en Aplicacións dentro do teu cartafol persoal.

En PowerShell:

powershell -ExecutionPolicy Bypass -c "irm https://github.com/iagonunez/oqman/releases/latest/download/install.ps1 | iex"

Windows 10/11 de 64 bits. Sen as C++ Build Tools de Microsoft, primeiro ábrese o seu instalador: acéptao e deixa que remate. Despois OpenQ está no menú Inicio.

O instalador, oqman, compila OpenQ no teu ordenador. Máis adiante: oqman update · oqman uninstall.

Paso a paso

OpenQ compílase no teu propio ordenador co seu instalador, oqman. O instalador descarga o código da versión máis recente, instala o que precisa a compilación (Rust, un compilador de C e FFmpeg para o vídeo), compila OpenQ e engádeo ás túas aplicacións. Os teus espectáculos nunca se tocan.

Antes de comezar

Necesitas conexión a internet, varios gigabytes de espazo libre no disco e, en Linux e Windows, o contrasinal de administrador (úsase para instalar paquetes do sistema). A primeira instalación é a máis longa, porque compila o programa enteiro; nun ordenador antigo pode tardar moito. As actualizacións posteriores son máis rápidas, porque as dependencias xa están compiladas.

Linux

  1. Abre unha terminal, pega a orde de abaixo e preme Intro: 
    curl --proto '=https' --tlsv1.2 -fsSL https://github.com/iagonunez/oqman/releases/latest/download/install.sh | sh
  2. O primeiro paso descarga o instalador, comproba a suma de control publicada e gárdao en ~/.local/bin. Despois arranca.
  3. Cando amose os paquetes do sistema que precisa (un compilador de C, libclang, as cabeceiras de son ALSA e PipeWire, udev e FFmpeg), pregunta antes de instalalos co xestor de paquetes da túa distribución. Responde que si; o xestor pedirá o contrasinal.
  4. Se o ordenador non ten Rust, oqman instala unha copia privada na súa propia carpeta. O Rust que xa haxa no sistema non se toca.
  5. A compilación amosa cada paquete que compila. Deixa a terminal aberta ata que diga que OpenQ está instalado.
  6. Abre OpenQ desde o menú de aplicacións (busca «OpenQ»), ou escribe openq nunha terminal.

Se a terminal di openq: orde non atopada, ~/.local/bin aínda non está no teu PATH. Engádea unha vez e abre unha terminal nova:

fish_add_path ~/.local/bin                                 # fish
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc   # bash (zsh: ~/.zshrc)

macOS

  1. Abre Terminal (preme ⌘ Espazo e escribe «Terminal»).
  2. Pega a orde de abaixo e preme Intro: 
    curl --proto '=https' --tlsv1.2 -fsSL https://github.com/iagonunez/oqman/releases/latest/download/install.sh | sh
  3. Se o Mac aínda non ten as Command Line Tools de Apple, macOS abre o seu instalador. Acepta a licenza de Apple, agarda a que remate e volve executar a mesma orde.
  4. oqman compila FFmpeg desde o seu código fonte, o que leva tempo. Nun Mac Intel compila tamén NASM, o ensamblador que usa FFmpeg.
  5. A app queda en ~/Applications/OpenQ.app, a carpeta Applications da túa carpeta persoal. Ábrea desde o Finder (Ir → Carpeta persoal → Applications) ou con Spotlight. Como a compilaches neste Mac, macOS non amosa o aviso de «desenvolvedor non identificado».

Windows

  1. Abre PowerShell: preme a tecla Inicio, escribe PowerShell e preme Intro.
  2. Pega a orde de abaixo e preme Intro: 
    powershell -ExecutionPolicy Bypass -c "irm https://github.com/iagonunez/oqman/releases/latest/download/install.ps1 | iex"
  3. Se o ordenador non ten as C++ Build Tools de Microsoft, ábrese o seu instalador coa carga de traballo «Desenvolvemento para escritorio con C++» marcada. Acepta a licenza de Microsoft e agarda a que remate; é grande e pode tardar. Despois oqman continúa só na mesma xanela.
  4. oqman descarga FFmpeg (a versión compartida LGPL) e libclang de LLVM, e compila OpenQ.
  5. Ao rematar, OpenQ está no menú Inicio e en Configuración → Aplicacións → Aplicacións instaladas.

Se algo falla

  • oqman doctor amosa o que está instalado e o que aínda lle falta á compilación.
  • Se a compilación se detén, le as últimas liñas que amosa, corrixe a causa (case sempre un paquete que falta ou un instalador cancelado) e volve executar a orde. O que xa se compilou consérvase, así que o segundo intento é máis rápido.

Actualizar e desinstalar

Para obter unha versión máis nova, executa oqman update: recompila OpenQ cando sae unha versión nova. Para quitar OpenQ, executa oqman uninstall; pregunta antes. Con --purge quita tamén o Rust, as dependencias e a caché de compilación de oqman. En Windows tamén podes quitalo desde Configuración → Aplicacións → Aplicacións instaladas. Os teus espectáculos nunca se tocan.
