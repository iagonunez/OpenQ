OpenQ for Windows (64-bit)
==========================

Run OpenQ.exe. Keep the .dll files in the same folder: they are the FFmpeg libraries used to
play video.

Windows may show "Windows protected your PC" the first time, because this build is not
code-signed. Click "More info", then "Run anyway".

Your firewall may ask about network access. Allow it on private networks if you use remote
devices (TCP 53200, UDP 53201) or OSC (UDP 53000).

User manual: Help → User manual (F1) in OpenQ, or Manual/index.html in this folder.
